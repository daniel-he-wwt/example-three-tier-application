# Development Story — Add DELETE /tasks/:id + Frontend Delete Button

## Goal
Users can delete a task permanently. The Express API exposes `DELETE /tasks/:id`; the Next.js frontend renders a delete button on every task row that calls it.

---

## Tasks

### 1. API — add `DELETE /tasks/:id` route (`src/api/index.js`)

After the existing `PATCH /tasks/:id` block, insert:

```js
// DELETE /tasks/:id — delete a task
app.delete('/tasks/:id', async (req, res) => {
  const id = parseInt(req.params.id, 10);
  const { rows } = await db.query('SELECT id FROM tasks WHERE id = $1', [id]);
  if (rows.length === 0) return res.status(404).json({ error: 'Not found' });
  await db.query('DELETE FROM tasks WHERE id = $1', [id]);
  res.status(204).send();
});
```

**Behaviour:**
- `204 No Content` on success (consistent with REST convention for DELETE).
- `404 Not Found` with `{ "error": "Not found" }` when the id doesn't exist.
- Parses `:id` as an integer, same as PATCH.

---

### 2. Server Action — add `deleteTask` (`src/web/app/actions.ts`)

Append after `toggleTask`:

```ts
export async function deleteTask(id: number) {
  await fetch(`${API_URL}/tasks/${id}`, { method: 'DELETE' });
  revalidatePath('/');
}
```

---

### 3. Frontend — add delete button per task (`src/web/app/page.tsx`)

Inside the `tasks.map(...)` `<li>`, after the existing toggle form, add a second inline server form:

```tsx
<form
  action={async () => {
    'use server';
    await deleteTask(task.id);
  }}
>
  <button
    type="submit"
    className="ml-auto text-zinc-400 hover:text-red-500 dark:hover:text-red-400 transition-colors"
    aria-label="Delete task"
  >
    <svg viewBox="0 0 16 16" className="w-4 h-4" fill="none" stroke="currentColor" strokeWidth="1.5" strokeLinecap="round" strokeLinejoin="round">
      <path d="M2 4h12M5 4V2h6v2M6 7v5M10 7v5M3 4l1 9h8l1-9" />
    </svg>
  </button>
</form>
```

Import `deleteTask` at the top of the file alongside the other actions.

---

## Acceptance Criteria

- `DELETE /tasks/1` returns `204` and the task is removed from the database.
- `DELETE /tasks/999` (non-existent) returns `404 { "error": "Not found" }`.
- A trash/delete icon appears on every task row in the UI.
- Clicking the delete button removes the task and the list re-renders without a page reload prompt.
- Existing `GET`, `POST`, and `PATCH` endpoints are unaffected.
- `npm run lint` in `src/web/` passes with no new errors.
